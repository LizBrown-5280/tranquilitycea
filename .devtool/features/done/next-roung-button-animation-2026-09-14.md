# Next Roung button Animation

Once the `Next Round` button is available, some animation should happen to indicate that the button is now enabled.  Maybe a little bounce or having it grow and shrink with some bounce.  It should last no longer than 3 secs.  We'll talk about this to determine what is the best solution for this.

## Completed

Added a 900ms bounce pulse when `Next Round` transitions to enabled. The pulse respects the user's reduced-motion preference.
